# Portfolio de Luis Hostos

Portfolio estático con Vite, HTML, CSS y JavaScript.

## Desarrollo

- `npm run dev`: servidor local.
- `npm run build`: genera las cuatro páginas y recursos en `dist/`.
- `npm run preview`: revisa la compilación.

Las rutas relativas permiten publicar en GitHub Pages bajo /portfolio-2026/. El repositorio publicado conserva los archivos compilados en la raíz y este proyecto editable en `source/`. Para actualizar: compilar en `source/` y copiar el contenido de `source/dist/` a la raíz, conservando `.git` y `source/`.

## Contenido

- `index.html`: presentación, trabajo publicado, servicios y contacto.
- `about.html`: experiencia, formación y stack.
- `projects.html`: ocho casos; lista en móvil y carrusel en escritorio.
- `src/style.css`: estilos compartidos; cada página tiene su CSS.
- `public/LUIS-HOSTOS-CV.pdf`: CV proporcionado por Luis.

La experiencia se basa en el CV y en el contenido original. Los proyectos internos se presentan sin capturas, datos ni enlaces privados. Las capturas de NOOVA y Deriva provienen de sus sitios públicos. No se publican precios ni métricas no verificadas.

La web respeta movimiento reducido, funciona sin JavaScript en modo lista y guarda el tema cuando el navegador permite almacenamiento. Las fuentes están alojadas localmente con sus licencias.
